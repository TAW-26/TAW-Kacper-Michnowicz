## Widok Główny: Przeglądanie Obiektów

### Header

- Pasek wyszukiwania (filtrowanie po nazwie lub typie boiska).

- Przycisk "Zaloguj / Zarejestruj".

### Sekcja Główna:

- Karty Obiektów: Każda karta zawiera zdjęcie, nazwę boiska oraz status.

- Na każdej karcie przycisk "Sprawdź grafik" lub "Zarezerwuj".

## Widok Szczegółów i Rezerwacji


- Sekcja Informacyjna, galeria zdjęć, opis techniczny.

- Interaktywny kalendarz.

- Panel rezerwacji.


## Widok Profilu Użytkownika

- Moje Rezerwacje: lista zarezerwowanych obiektów.

- Historia poprzednich rezerwacji.

- Status płatności.

- Opcje
